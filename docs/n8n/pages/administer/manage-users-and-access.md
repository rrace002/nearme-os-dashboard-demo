# Manage users and access

User management in n8n allows you to invite people to work in your n8n instance. It includes:

* Login and password management
* Adding and removing users
* Three built-in [instance roles](/administer/manage-users-and-access/understand-instance-roles.md): **Owner**, **Admin**, and **Member** (**Admin** is available on n8n Cloud Pro, Enterprise, and self-hosted Enterprise), plus custom instance roles

{% hint style="info" %}
**Privacy**

The user management feature doesn't send personal information, such as email or username, to n8n.
{% endhint %}
