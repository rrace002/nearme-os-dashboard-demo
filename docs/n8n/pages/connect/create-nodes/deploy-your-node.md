# Deploy your node

This section contains details on how to deploy and share your node.

You can choose to:

* [Submit your node to the community node repository](/connect/create-nodes/deploy-your-node/submit-community-nodes.md). This makes it available for everyone to use, and allows you to [install and use it](/integrations/community-nodes/installation-and-management.md) like any other community node. This is the only way to use custom nodes on cloud.
* Install the node into your n8n instance as a [private node](/connect/create-nodes/deploy-your-node/install-private-nodes.md).
