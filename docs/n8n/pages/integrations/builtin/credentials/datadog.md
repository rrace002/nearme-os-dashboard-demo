# Datadog credentials

You can use these credentials to authenticate when using the [HTTP Request node](/integrations/builtin/core-nodes/n8n-nodes-base.httprequest.md) to make a [Custom API call](/integrations/builtin/custom-api-actions-for-existing-nodes.md).

## Prerequisites <a href="#prerequisites" id="prerequisites"></a>

Create a [Datadog](https://app.datadoghq.eu/signup) account.

## Related resources <a href="#related-resources" id="related-resources"></a>

Refer to [Datadog's API documentation](https://docs.datadoghq.com/api/latest/) for more information about authenticating with the service.

This is a credential-only node. Refer to [Custom API operations](/integrations/builtin/custom-api-actions-for-existing-nodes.md) to learn more. View [example workflows and related content](https://n8n.io/integrations/datadog/) on n8n's website.

## Using API Key <a href="#using-api-key" id="using-api-key"></a>

To configure this credential, you'll need:

* Your Datadog instance **Host**
* An **API Key**
* An **App Key**

Refer to [Authentication](https://docs.datadoghq.com/api/latest/authentication/) on Datadog's website for more information.
