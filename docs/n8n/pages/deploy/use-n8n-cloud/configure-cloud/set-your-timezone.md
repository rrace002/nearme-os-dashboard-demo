# Set your timezone

You can change the timezone for your n8n instance. This affects the [Schedule Trigger](/integrations/builtin/core-nodes/n8n-nodes-base.scheduletrigger.md) and [Date & Time node](/integrations/builtin/core-nodes/n8n-nodes-base.datetime.md). Users can configure the timezone for individual workflows in [Workflow settings](/build/manage-workflows/configure-workflow-settings.md).

1. On your dashboard, select **Manage**.
2. Change the **Timezone** dropdown to the timezone you want.
